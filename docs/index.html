出 ipa 的两条路

① 有 Mac：一条命令
cd carplayer-ios
./scripts/build_ipa.sh                              # 未签名 → dist/*.ipa
TEAM_ID=你的团队ID ./scripts/build_ipa.sh signed     # 带签名 → 可直接装机/上架
或直接 open CarPlayer.xcodeproj → 选 Team → ⌘R 真机运行 / Product → Archive。
② 没有 Mac：GitHub Actions 自动出包
git init && git add . && git commit -m "CarPlayer iOS 1.9.14"
git remote add origin git@github.com:你的账号/carplayer-ios.git
git push -u origin main
# Actions → iOS Build (unsigned ipa) → Run workflow → 下载 Artifact
workflow 已内置在 .github/workflows/ios-build.yml，用 macos-15-intel + Xcode 16.4 免签名编译并打包 Payload → ipa。
tools/push_github.py 已把「建库 → 推送 → 触发 → 抓 ipa → 更新本页」全部自动化，单次约 2 分半。

需要注意

ipa 是「编译 + 签名」产物，Windows 上没有 Xcode 就产不出二进制包 —— 这一步只能由 macOS 完成（本机或 GitHub Actions 的 macOS runner）。
所以下载页给的是可直接编译的完整工程 + 两条一键出包路径，而不是一个装不上的空壳 ipa。

另：与 Android 版一致，本版不带内置播放音源。到「设置 → 导入音源」导入 LX 的 .js 脚本，或导入青听的 music.json，之后搜索到的歌即可播放（AES/MD5/Base64/HTTP 桥均已实现，仅 RSA 工具留空实现）。
